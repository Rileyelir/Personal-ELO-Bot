# ⚔️ Personal ELO Bot (PELOB) ⚔️

---

## What Is PELOB ❓
**PELOB** is a self-hostable and easily customizable Discord bot that can handle ELO calculations using *TrueSkill*™ and provide matchmaking server-wide with other features geared towards competitive gaming in your community. 

## Features 📋

- Customization of Text & Colors
- Server Leaderboard
- Challenges *(either by match quality or by preference)*
- Matchmaking Queue
- *TrueSkill*™ ELO Ratings
- Player Reports *(win rate, character, rating, match history, etc)*
- Admin Commands *(rating reset, rating restore, challenge dispute tools)*
- Open Source on MIT License

## Who is this for ❓
**PELOB** is designed for Discord servers centered around smaller competitive games, and it is found more effective when those games lack a proper ranking system.


It can be very helpful for indie games geared towards a competitive nature, giving a proper ranked system that is accessible in their community; additionally, this fosters both server growth and activity within both Discord and the game.


**PELOB** is also useful for "Discord Fighters", a term coined by the FGC for fighting games that almost always require Discord to find matches due to the game's low population. If you have a server for one of these games, consider hosting this bot for your members!

## Why would I host this ❓
**PELOB** offers personalization/customization that no other bot could offer! **PELOB** comes with a customization file that allows you to change most or all lines of text that the bot uses, being able to fully customize it to match the theme and tone of the game you're playing. You can also change every embed's color to whatever you want on an RGB scale!

Along with this, **PELOB** is yours. You make your own bot on the Discord Developer Portal, having full access to its profile picture, description, name, and whatever else you could want.

In addition to all of this, **PELOB** is *fully* open source and written in Python, meaning it is easy to go into the code and add, change, or remove features. Details of how the project functions and what modules/libraries it runs on will be found in the GitHub Wiki.
